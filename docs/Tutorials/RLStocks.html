RL and Trading in Futures Markets 101: A Deep Q-Network for Cocoa

Written in 2024. All examples use public data and are for learning only, not investment advice.

In Reinforcement Learning 101 we used a Q-table with 18 states. Here we replace the table with a neural network, a Deep Q-Network (DQN), so the agent can observe many continuous features at once. We build a custom trading environment for ICE cocoa futures with the gymnasium API and train a DQN with stable-baselines3.

Cocoa is a demanding test case: the 2023/24 season delivered the largest rally in the market’s history, with prices above $10,000/t in April 2024. Any agent trained on the decade before will face conditions it has never seen.

2. Features for the agent

import numpy as np
import pandas as pd
import yfinance as yf

px = yf.download("CC=F", start="2010-01-01", end="2024-06-30")["Close"].squeeze()
ret = np.log(px).diff()

feat = pd.DataFrame({
    "ret_1d": ret,
    "ret_5d": ret.rolling(5).sum(),
    "ret_20d": ret.rolling(20).sum(),
    "ret_60d": ret.rolling(60).sum(),
    "vol_20d": ret.rolling(20).std(),
    "dist_ma100": px / px.rolling(100).mean() - 1,
}).dropna()
next_ret = ret.shift(-1).reindex(feat.index)

train_idx = feat.index < "2019-01-01"
mu, sd = feat[train_idx].mean(), feat[train_idx].std()
feat_z = ((feat - mu) / sd).clip(-5, 5)    # scale with training statistics only

A note on data: CC=F is a continuous front-month series that jumps at each contract roll. For research beyond a tutorial, build a roll-adjusted series from individual contract months.

3. The trading environment

The agent chooses short, flat or long each day. The reward is the next day’s return on the chosen position, minus a cost whenever the position changes. The current position is part of the observation so the agent can weigh trading costs.

import gymnasium as gym
from gymnasium import spaces

class FuturesEnv(gym.Env):
    def __init__(self, features, next_returns, cost=0.0005, episode_len=250):
        super().__init__()
        self.X = features.values.astype(np.float32)
        self.r = next_returns.values.astype(np.float32)
        self.cost, self.episode_len = cost, episode_len
        self.action_space = spaces.Discrete(3)        # 0 short, 1 flat, 2 long
        self.observation_space = spaces.Box(-np.inf, np.inf, shape=(self.X.shape[1] + 1,), dtype=np.float32)

    def _obs(self):
        return np.append(self.X[self.t], self.pos).astype(np.float32)

    def reset(self, seed=None, options=None):
        super().reset(seed=seed)
        self.t = self.np_random.integers(0, len(self.X) - self.episode_len - 1)
        self.end = self.t + self.episode_len
        self.pos = 0.0
        return self._obs(), {}

    def step(self, action):
        new_pos = float(action) - 1.0
        reward = new_pos * self.r[self.t] - self.cost * abs(new_pos - self.pos)
        self.pos = new_pos
        self.t += 1
        terminated = self.t >= self.end
        return self._obs(), float(reward), terminated, False, {}

Each episode is a random one-year slice of history, which gives the agent many different market conditions to learn from.

4. Training the DQN

from stable_baselines3 import DQN

train_env = FuturesEnv(feat_z[train_idx], next_ret[train_idx])

model = DQN(
    "MlpPolicy", train_env,
    learning_rate=1e-4, buffer_size=50_000, batch_size=64,
    gamma=0.95, exploration_fraction=0.3, exploration_final_eps=0.05,
    policy_kwargs={"net_arch": [64, 64]}, seed=0, verbose=0,
)
model.learn(total_timesteps=200_000)

The key DQN ideas are all inside stable-baselines3:

  • Experience replay: past transitions are stored in a buffer and sampled at random, which breaks the correlation between consecutive days.
  • Target network: a slowly updated copy of the network provides stable learning targets.
  • ε-greedy exploration: the agent acts randomly at first and gradually relies on its learned values.

5. Out-of-sample evaluation

test_X = feat_z[~train_idx]
test_r = next_ret[~train_idx].fillna(0)

pos, pnl, positions = 0.0, [], []
for i in range(len(test_X)):
    obs = np.append(test_X.values[i], pos).astype(np.float32)
    action, _ = model.predict(obs, deterministic=True)
    new_pos = float(action) - 1.0
    pnl.append(new_pos * test_r.values[i] - 0.0005 * abs(new_pos - pos))
    pos = new_pos
    positions.append(pos)

pnl = pd.Series(pnl, index=test_X.index)
print("Cumulative log return:", round(pnl.sum(), 3))
print("Buy and hold:", round(test_r.sum(), 3))
print("Annualised Sharpe:", round(np.sqrt(252) * pnl.mean() / pnl.std(), 2))
print("Share of days long / flat / short:",
      pd.Series(positions).value_counts(normalize=True).round(2).to_dict())

Check performance separately for 2019–2022 and for 2023–24. If the agent made most of its money in the 2024 rally simply by being long, it has learned “cocoa goes up”, not a robust strategy.

6. Making it more realistic

Before trusting any RL trading result, add:

  • Proper contracts and rolls rather than a continuous series.
  • Realistic costs: exchange fees, bid-ask spreads and slippage, which widen sharply in volatile markets such as 2024 cocoa.
  • Position sizing and risk limits: scale positions by volatility and cap drawdowns.
  • Walk-forward training: retrain on an expanding window and test on the following period, repeatedly.
  • Multiple seeds: RL results vary a lot between runs; report the spread, not the best run.

7. What RL is good for in commodities

Pure price-based trading agents rarely survive these checks. RL is more promising where the decision itself is the hard part: execution (how to work a large order), hedging programmes for producers and roasters, and inventory and storage decisions where carry, freight and timing interact.
