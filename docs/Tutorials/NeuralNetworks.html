Deep Learning for Time Series: LSTM and CNN Forecasts for Cotton

Written in 2024. All examples use public data and are for learning only, not investment advice.

Recurrent and convolutional neural networks can learn patterns across several input series at once, which makes them tempting for commodity forecasting. They can also overfit spectacularly. In this tutorial we build LSTM and 1D-CNN models for weekly cotton (ICE Cotton No.2) returns with a few exogenous drivers, and test them honestly against simple benchmarks.

1. Why cotton and which drivers?

Cotton prices respond to:

  • The US dollar: the US is the largest exporter, so a stronger dollar makes US cotton dearer abroad.
  • Crude oil: polyester, cotton’s main substitute, is made from oil.
  • Other markets’ risk appetite: cotton often trades with broader commodity and equity sentiment, captured here by the S&P 500.
import numpy as np
import pandas as pd
import yfinance as yf

tickers = {"cotton": "CT=F", "dxy": "DX-Y.NYB", "crude": "CL=F", "spx": "^GSPC"}
raw = yf.download(list(tickers.values()), start="2005-01-01", end="2024-06-30", interval="1wk")["Close"]
raw = raw.rename(columns={v: k for k, v in tickers.items()}).dropna()
rets = np.log(raw).diff().dropna()

2. Turning series into supervised windows

Each sample is the previous 26 weeks of all four return series; the target is next week’s cotton return.

def make_windows(df, target_col, lookback=26):
    values = df.values
    t_idx = df.columns.get_loc(target_col)
    X, y = [], []
    for i in range(lookback, len(df)):
        X.append(values[i - lookback:i])   # weeks i-lookback ... i-1
        y.append(values[i, t_idx])         # week i, the one after the window
    return np.array(X), np.array(y)

The window covers weeks i-26 to i-1 and the target is week i, the week immediately after it. Checking this indexing is worth five minutes, because an off-by-one error here produces a “perfect” model that is just reading the answer.

X, y = make_windows(rets, "cotton", lookback=26)
dates = rets.index[26:]   # date of each target week

train = dates < "2018-01-01"
valid = (dates >= "2018-01-01") & (dates < "2021-01-01")
test  = dates >= "2021-01-01"

# Scale using training statistics only
mu = X[train].reshape(-1, X.shape[2]).mean(0)
sd = X[train].reshape(-1, X.shape[2]).std(0)
X = (X - mu) / sd
y_scale = y[train].std()
y_s = y / y_scale

3. An LSTM model

from tensorflow import keras
from tensorflow.keras import layers

def build_lstm(n_steps, n_feat):
    model = keras.Sequential([
        layers.Input(shape=(n_steps, n_feat)),
        layers.LSTM(32),
        layers.Dropout(0.3),
        layers.Dense(16, activation="relu"),
        layers.Dense(1),
    ])
    model.compile(optimizer=keras.optimizers.Adam(1e-3), loss="mae")
    return model

lstm = build_lstm(X.shape[1], X.shape[2])
stop = keras.callbacks.EarlyStopping(patience=20, restore_best_weights=True)
hist = lstm.fit(X[train], y_s[train], validation_data=(X[valid], y_s[valid]),
                epochs=300, batch_size=32, callbacks=[stop], verbose=0)
print("Stopped after", len(hist.history["loss"]), "epochs")

Small networks, dropout and early stopping are not optional with a few hundred weekly samples.

4. A 1D convolutional model

CNNs scan the window with filters that detect short patterns (for example, a sharp dollar move followed by cotton weakness):

def build_cnn(n_steps, n_feat):
    model = keras.Sequential([
        layers.Input(shape=(n_steps, n_feat)),
        layers.Conv1D(16, kernel_size=4, activation="relu"),
        layers.MaxPooling1D(2),
        layers.Conv1D(16, kernel_size=4, activation="relu"),
        layers.GlobalAveragePooling1D(),
        layers.Dropout(0.3),
        layers.Dense(1),
    ])
    model.compile(optimizer="adam", loss="mae")
    return model

cnn = build_cnn(X.shape[1], X.shape[2])
cnn.fit(X[train], y_s[train], validation_data=(X[valid], y_s[valid]),
        epochs=300, batch_size=32, callbacks=[stop], verbose=0)

5. Honest evaluation

from sklearn.metrics import mean_absolute_error
from sklearn.linear_model import Ridge

def report(name, pred):
    mae = mean_absolute_error(y[test], pred)
    hit = (np.sign(pred) == np.sign(y[test])).mean()
    print(f"{name:8s} MAE={mae:.4f}  hit rate={hit:.3f}")

report("Zero", np.zeros(test.sum()))
ridge = Ridge(alpha=10).fit(X[train].reshape(train.sum(), -1), y[train])
report("Ridge", ridge.predict(X[test].reshape(test.sum(), -1)))
report("LSTM", lstm.predict(X[test], verbose=0).ravel() * y_scale)
report("CNN", cnn.predict(X[test], verbose=0).ravel() * y_scale)

Run the networks with several random seeds. If results swing with the seed, you are looking at noise, not skill.

6. Where deep learning does help in softs

Weekly returns are close to unpredictable, so do not be surprised if the zero forecast is hard to beat. Neural networks earn their keep in richer problems:

  • Crop yield from sequences of daily weather and satellite vegetation indices over a season.
  • Physical flows: forecasting port arrivals or shipments from historical patterns and weather.
  • Text: classifying crop reports, weather bulletins or news by sentiment.
  • Images: detecting crop disease or land use, covered in Image classification.
