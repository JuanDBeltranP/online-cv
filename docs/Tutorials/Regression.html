Regression 101: What Drives Sugar Prices?

Written in 2024. All examples use public data and are for learning only, not investment advice.

Raw sugar (ICE Sugar No.11) is one of the best markets to learn regression on, because two of its macro drivers are well understood:

  • The Brazilian real. Brazil is by far the largest sugar exporter and mills earn in dollars but pay costs in reais. A weaker real (USD/BRL up) makes selling sugar abroad more attractive in local terms, which tends to weigh on prices.
  • Crude oil. Brazilian mills can turn cane into sugar or ethanol. When oil (and so ethanol) prices are high, more cane goes to ethanol and less sugar reaches the market, which tends to support sugar.

We will test these relationships with linear models in Python, from ordinary least squares to regularised regression and a decision tree.

1. Setting up

!pip install yfinance pandas numpy scikit-learn matplotlib
import numpy as np
import pandas as pd
import yfinance as yf
import matplotlib.pyplot as plt

2. Getting the data

We use weekly front-month futures and currency prices from Yahoo Finance: sugar (SB=F), WTI crude (CL=F), USD/BRL (BRL=X) and the US dollar index (DX-Y.NYB).

tickers = {"sugar": "SB=F", "crude": "CL=F", "usdbrl": "BRL=X", "dxy": "DX-Y.NYB"}
raw = yf.download(list(tickers.values()), start="2010-01-01", end="2024-06-30", interval="1wk")["Close"]
raw = raw.rename(columns={v: k for k, v in tickers.items()}).dropna()
raw.tail()

3. Levels or returns?

Regressing one price level on another almost always gives an impressive R² that means nothing: both series trend, so they look related even when they are not (a “spurious regression”). The safer approach is to model weekly percentage changes.

rets = np.log(raw).diff().dropna()
rets.corr().round(2)

You should see a negative correlation between sugar and USD/BRL, and a positive one between sugar and crude, in line with the story above.

4. Train and test split, in time order

Never shuffle time series. Train on the past, test on the most recent data:

X = rets[["crude", "usdbrl", "dxy"]]
y = rets["sugar"]

split = int(len(rets) * 0.8)
X_train, X_test = X.iloc[:split], X.iloc[split:]
y_train, y_test = y.iloc[:split], y.iloc[split:]

from sklearn.preprocessing import StandardScaler
scaler = StandardScaler().fit(X_train)          # fit on training data only
X_train_s, X_test_s = scaler.transform(X_train), scaler.transform(X_test)

5. Ordinary least squares

from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score, mean_absolute_error

ols = LinearRegression().fit(X_train_s, y_train)
pred = ols.predict(X_test_s)

print(dict(zip(X.columns, ols.coef_.round(4))))
print("Test R2:", round(r2_score(y_test, pred), 3))

For proper inference (standard errors, p-values) use statsmodels:

import statsmodels.api as sm
model = sm.OLS(y_train, sm.add_constant(X_train)).fit(cov_type="HAC", cov_kwds={"maxlags": 4})
print(model.summary())

The HAC option corrects the standard errors for autocorrelation, which weekly commodity returns usually have.

Reading the result. These are contemporaneous relationships: they explain how sugar moves alongside the real and oil in the same week. They do not forecast next week. That is a useful distinction when someone shows you a model with a high R².

6. Lasso, Ridge and Elastic Net

Regularisation shrinks coefficients to fight overfitting, which matters as soon as you add many correlated drivers (other currencies, freight, fertiliser prices, weather indices).

from sklearn.linear_model import Lasso, Ridge, ElasticNet

for name, m in {"Lasso": Lasso(alpha=0.001),
                "Ridge": Ridge(alpha=1.0),
                "ElasticNet": ElasticNet(alpha=0.001, l1_ratio=0.5)}.items():
    m.fit(X_train_s, y_train)
    print(name, dict(zip(X.columns, m.coef_.round(4))),
          "R2:", round(r2_score(y_test, m.predict(X_test_s)), 3))

Lasso can set weak drivers exactly to zero, which makes it a handy first filter when you have dozens of candidate variables.

7. A decision tree

Trees capture non-linear effects, such as the ethanol link only mattering when oil is high enough for ethanol parity to bind.

from sklearn.tree import DecisionTreeRegressor
tree = DecisionTreeRegressor(max_depth=3, min_samples_leaf=30).fit(X_train, y_train)
print("Tree R2:", round(r2_score(y_test, tree.predict(X_test)), 3))

A shallow tree usually does no better than the linear model here, which is itself a finding: these macro relationships are close to linear in returns.

8. Checking stability

Relationships change. A rolling regression shows whether the real and oil still matter as much as they used to:

from statsmodels.regression.rolling import RollingOLS
roll = RollingOLS(rets["sugar"], sm.add_constant(rets[["crude", "usdbrl"]]), window=104).fit()
roll.params[["crude", "usdbrl"]].plot(title="Two-year rolling betas for sugar")
plt.axhline(0, color="grey", lw=0.8)
plt.show()

If the betas drift, a model trained on 2015 to 2020 can mislead you in 2024. Policy shocks such as India’s export restrictions in 2023 are exactly the kind of event that a macro regression cannot see.
