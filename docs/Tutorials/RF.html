Random Forest 101: Predicting Coffee’s Weekly Direction

Written in 2024. All examples use public data and are for learning only, not investment advice.

A random forest is a collection of decision trees, each trained on a random sample of the data and features, whose votes are averaged. Forests handle non-linear relationships, need little preprocessing and rarely overfit badly, which makes them a solid first model for market data.

Here we classify whether arabica coffee (ICE Coffee “C”) will rise or fall over the next week, using price-based features and speculative positioning from the CFTC.

1. Data

  • Prices: weekly front-month arabica from Yahoo Finance (KC=F).
  • Positioning: the CFTC Commitments of Traders (COT) disaggregated report, which splits open interest into producers, swap dealers and managed money (funds). Funds’ net position is widely watched in softs because crowded positions can unwind sharply.
import io, zipfile, requests
import numpy as np
import pandas as pd
import yfinance as yf

px = yf.download("KC=F", start="2012-01-01", end="2024-06-30", interval="1wk")["Close"].squeeze()

def load_cot(year):
    url = f"https://www.cftc.gov/files/dea/history/fut_disagg_txt_{year}.zip"
    z = zipfile.ZipFile(io.BytesIO(requests.get(url).content))
    return pd.read_csv(z.open(z.namelist()[0]), low_memory=False)

cot = pd.concat(load_cot(y) for y in range(2012, 2025))
cot = cot[cot["Market_and_Exchange_Names"].str.startswith("COFFEE C")]
cot["date"] = pd.to_datetime(cot["Report_Date_as_YYYY-MM-DD"])
cot = cot.set_index("date").sort_index()
cot["mm_net_pct_oi"] = (cot["M_Money_Positions_Long_All"] - cot["M_Money_Positions_Short_All"]) / cot["Open_Interest_All"]

COT data are as of Tuesday but published on Friday, so we lag them by one week before use. Ignoring publication lags is one of the easiest ways to fool yourself.

2. Features

df = pd.DataFrame({"px": px})
df["ret"] = np.log(df["px"]).diff()

X = pd.DataFrame(index=df.index)
X["ret_1w"]  = df["ret"]
X["ret_4w"]  = df["ret"].rolling(4).sum()
X["ret_13w"] = df["ret"].rolling(13).sum()
X["vol_13w"] = df["ret"].rolling(13).std()
X["dist_ma26"] = df["px"] / df["px"].rolling(26).mean() - 1
X["week_of_year"] = df.index.isocalendar().week.astype(int)   # Brazil harvest / frost seasonality

cot_w = cot["mm_net_pct_oi"].resample("W-SUN").last().shift(1)  # publication lag
X = X.join(cot_w.rename("mm_net")).ffill()
X["mm_net_chg_4w"] = X["mm_net"].diff(4)

y = (df["ret"].shift(-1) > 0).astype(int)   # 1 if next week is up
data = X.join(y.rename("up")).dropna()

The week-of-year feature lets the forest pick up seasonality: the Brazilian harvest from roughly May to September, and the frost-risk window in June to August that has driven some of arabica’s biggest rallies.

3. Training, in time order

from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, classification_report

train = data.loc[:"2020-12"]
test  = data.loc["2021-01":]
X_train, y_train = train.drop(columns="up"), train["up"]
X_test,  y_test  = test.drop(columns="up"),  test["up"]

rf = RandomForestClassifier(n_estimators=500, max_depth=4, min_samples_leaf=20,
                            random_state=42, n_jobs=-1)
rf.fit(X_train, y_train)

pred = rf.predict(X_test)
print("Accuracy:", round(accuracy_score(y_test, pred), 3))
print("Base rate (always up):", round(y_test.mean(), 3))
print(classification_report(y_test, pred))

Compare accuracy with the base rate. In a trending market, “always up” can look like 55% accuracy without any skill.

4. Tuning with time-series cross-validation

from sklearn.model_selection import GridSearchCV, TimeSeriesSplit

grid = GridSearchCV(
    RandomForestClassifier(random_state=42, n_jobs=-1),
    {"n_estimators": [300, 600], "max_depth": [3, 4, 6], "min_samples_leaf": [10, 20, 40]},
    cv=TimeSeriesSplit(n_splits=5), scoring="roc_auc",
)
grid.fit(X_train, y_train)
print(grid.best_params_, round(grid.best_score_, 3))

We score with ROC AUC, which judges how well the model ranks up-weeks above down-weeks, regardless of the 50% threshold.

5. What did the forest learn?

Built-in feature importances are biased towards continuous variables. Permutation importance on the test set is more honest:

from sklearn.inspection import permutation_importance
imp = permutation_importance(grid.best_estimator_, X_test, y_test, scoring="roc_auc",
                             n_repeats=20, random_state=0)
pd.Series(imp.importances_mean, index=X_test.columns).sort_values().plot.barh()

Positioning features often matter most at extremes: when funds are very long, the downside risk from liquidation rises.

6. From probabilities to decisions

Instead of trading every week, act only when the model is confident:

proba = grid.best_estimator_.predict_proba(X_test)[:, 1]
signal = np.where(proba > 0.6, 1, np.where(proba < 0.4, -1, 0))
strategy = signal * df["ret"].shift(-1).reindex(X_test.index)
print("Weeks active:", (signal != 0).mean().round(2))
print("Cumulative log return:", strategy.sum().round(3))

This ignores costs, rolls and slippage, so treat it as a sanity check rather than a backtest.
