SQL 101: Building a Softs Market Database

Written in 2024. All examples use public data and are for learning only, not investment advice.

Every serious commodities desk sits on top of a database: futures prices, physical differentials, weather, shipments, positioning. Before any model, you need to be able to store and query that data cleanly. In this tutorial we build a small SQLite database for the four main softs (cocoa, coffee, sugar and cotton) and learn the core SQL commands along the way.

1. Setting up

SQLite needs no server. In Python it comes built in:

import sqlite3
con = sqlite3.connect("softs.db")
cur = con.cursor()

You can also use the command line (sqlite3 softs.db) or a GUI such as DB Browser for SQLite. Every SQL block below can be run with cur.execute("""...""").

2. Designing the tables

We will keep three tables:

  • contracts: one row per futures market (what it is, where it trades, its unit).
  • prices: daily settlement prices.
  • exports: monthly exports by origin country.
CREATE TABLE contracts (
    symbol      TEXT PRIMARY KEY,   -- e.g. 'CC'
    commodity   TEXT NOT NULL,      -- 'Cocoa'
    exchange    TEXT NOT NULL,      -- 'ICE US'
    unit        TEXT NOT NULL       -- 'USD/tonne'
);

CREATE TABLE prices (
    symbol      TEXT NOT NULL REFERENCES contracts(symbol),
    date        DATE NOT NULL,
    settle      REAL NOT NULL,
    volume      INTEGER,
    PRIMARY KEY (symbol, date)
);

CREATE TABLE exports (
    origin      TEXT NOT NULL,      -- 'Côte d''Ivoire'
    commodity   TEXT NOT NULL,
    month       DATE NOT NULL,      -- first day of the month
    tonnes      REAL NOT NULL,
    PRIMARY KEY (origin, commodity, month)
);

The composite primary keys stop you loading the same day or month twice, which is the most common data bug on a research desk.

3. Inserting data

INSERT INTO contracts VALUES
  ('CC', 'Cocoa',          'ICE US', 'USD/tonne'),
  ('KC', 'Coffee Arabica', 'ICE US', 'USc/lb'),
  ('SB', 'Sugar No.11',    'ICE US', 'USc/lb'),
  ('CT', 'Cotton No.2',    'ICE US', 'USc/lb');

In practice you load prices in bulk. A quick way to get continuous front-month prices for learning purposes is yfinance, then push the DataFrame into SQLite with pandas:

import yfinance as yf

tickers = {"CC": "CC=F", "KC": "KC=F", "SB": "SB=F", "CT": "CT=F"}
frames = []
for sym, tk in tickers.items():
    df = yf.download(tk, start="2015-01-01", end="2024-06-30")[["Close", "Volume"]]
    df = df.reset_index().rename(columns={"Date": "date", "Close": "settle", "Volume": "volume"})
    df["symbol"] = sym
    frames.append(df)

import pandas as pd
prices = pd.concat(frames)
prices.to_sql("prices", con, if_exists="append", index=False)

Continuous front-month series jump at every roll, so treat them as illustrative. For real analysis you would store individual contract months (e.g. CCN24) and build your own roll-adjusted series.

For exports, national statistics, the ICCO and the ICO publish monthly or quarterly figures; load them the same way with to_sql.

4. Querying

The latest cocoa prices:

SELECT date, settle
FROM prices
WHERE symbol = 'CC'
ORDER BY date DESC
LIMIT 10;

Filtering with conditions: every day in 2024 when cocoa settled above $10,000/t (it did, for the first time ever, in the spring of 2024):

SELECT date, settle
FROM prices
WHERE symbol = 'CC'
  AND date >= '2024-01-01'
  AND settle > 10000;

5. Aggregating

Average yearly price and volume per market:

SELECT symbol,
       strftime('%Y', date)  AS year,
       ROUND(AVG(settle), 2) AS avg_settle,
       SUM(volume)           AS total_volume
FROM prices
GROUP BY symbol, year
ORDER BY symbol, year;

HAVING filters after aggregation. Years in which arabica averaged above 200 USc/lb:

SELECT strftime('%Y', date) AS year, AVG(settle) AS avg_settle
FROM prices
WHERE symbol = 'KC'
GROUP BY year
HAVING AVG(settle) > 200;

6. Joining tables

Joins let you put context next to the numbers:

SELECT c.commodity, c.unit, p.date, p.settle
FROM prices p
JOIN contracts c ON c.symbol = p.symbol
WHERE p.date = (SELECT MAX(date) FROM prices);

Total cocoa exports by origin for the 2022/23 season (October to September):

SELECT origin, ROUND(SUM(tonnes) / 1000, 1) AS kt
FROM exports
WHERE commodity = 'Cocoa'
  AND month BETWEEN '2022-10-01' AND '2023-09-01'
GROUP BY origin
ORDER BY kt DESC;

Note that softs run on crop years, not calendar years: cocoa and coffee seasons usually start in October. Getting the season boundaries right is half the job.

7. Updating and deleting

-- correct a bad print
UPDATE prices SET settle = 7845 WHERE symbol = 'CC' AND date = '2024-03-01';

-- remove a duplicated load
DELETE FROM exports WHERE origin = 'Ghana' AND month = '2023-01-01';

Always run the matching SELECT first, so you can see exactly which rows will change.
