Image Classification with Deep Learning: Detecting Coffee Leaf Disease

Written in 2024. All examples use public data and are for learning only, not investment advice.

Plant disease is a supply story. Coffee leaf rust (Hemileia vastatrix) cut production sharply across Central America in 2012–13, and cocoa swollen shoot virus is one of the reasons West African cocoa output has struggled in recent seasons. Agronomists, cooperatives and exporters increasingly use phone photos and drones to spot disease early.

In this tutorial we train a convolutional neural network (CNN) to classify coffee leaf images as healthy or diseased, using transfer learning in Keras.

1. The data

Two open datasets on Mendeley Data work well:

  • RoCoLe (Robusta Coffee Leaf images, Ecuador): healthy leaves, red spider mite and rust at several severity levels.
  • JMuBEN (arabica leaves, Kenya): healthy leaves, leaf rust, Cercospora and Phoma.

Download one and arrange the images in one folder per class:

coffee_leaves/
    healthy/
    rust/
    cercospora/
    phoma/

2. How CNNs see an image

A CNN slides small filters across the image. Early layers detect edges and colours; deeper layers combine them into textures and shapes, such as the orange powdery spots of rust or the brown rings of Cercospora. Pooling layers shrink the image so later layers see larger areas.

Training a CNN from scratch needs a lot of images. Transfer learning starts from a network already trained on millions of everyday photos (ImageNet) and only retrains the top layers, which works well with a few thousand leaves.

3. Loading the images

import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

IMG = (224, 224)
train_ds = keras.utils.image_dataset_from_directory(
    "coffee_leaves", validation_split=0.2, subset="training", seed=42,
    image_size=IMG, batch_size=32)
val_ds = keras.utils.image_dataset_from_directory(
    "coffee_leaves", validation_split=0.2, subset="validation", seed=42,
    image_size=IMG, batch_size=32)

class_names = train_ds.class_names
print(class_names)

AUTOTUNE = tf.data.AUTOTUNE
train_ds = train_ds.cache().shuffle(1000).prefetch(AUTOTUNE)
val_ds = val_ds.cache().prefetch(AUTOTUNE)

Check the class balance. Disease datasets are often dominated by healthy leaves, and a model that always says “healthy” can look accurate while being useless.

4. Building the model

augment = keras.Sequential([
    layers.RandomFlip("horizontal_and_vertical"),
    layers.RandomRotation(0.2),
    layers.RandomZoom(0.15),
    layers.RandomContrast(0.2),
])

base = keras.applications.EfficientNetB0(include_top=False, weights="imagenet",
                                         input_shape=IMG + (3,))
base.trainable = False   # freeze the pretrained layers at first

inputs = keras.Input(shape=IMG + (3,))
x = augment(inputs)
x = keras.applications.efficientnet.preprocess_input(x)
x = base(x, training=False)
x = layers.GlobalAveragePooling2D()(x)
x = layers.Dropout(0.3)(x)
outputs = layers.Dense(len(class_names), activation="softmax")(x)
model = keras.Model(inputs, outputs)

model.compile(optimizer=keras.optimizers.Adam(1e-3),
              loss="sparse_categorical_crossentropy", metrics=["accuracy"])

Augmentation imitates real field photos: leaves at different angles, lighting and distances.

5. Training in two stages

stop = keras.callbacks.EarlyStopping(patience=5, restore_best_weights=True)
model.fit(train_ds, validation_data=val_ds, epochs=20, callbacks=[stop])

# Fine-tune: unfreeze the top of the base network with a small learning rate
base.trainable = True
for layer in base.layers[:-30]:
    layer.trainable = False
model.compile(optimizer=keras.optimizers.Adam(1e-5),
              loss="sparse_categorical_crossentropy", metrics=["accuracy"])
model.fit(train_ds, validation_data=val_ds, epochs=10, callbacks=[stop])

6. Evaluating properly

import numpy as np
from sklearn.metrics import classification_report, confusion_matrix

y_true = np.concatenate([y.numpy() for _, y in val_ds])
y_pred = np.argmax(model.predict(val_ds), axis=1)

print(classification_report(y_true, y_pred, target_names=class_names))
print(confusion_matrix(y_true, y_pred))

Focus on recall for the disease classes: a missed rust case costs much more than a false alarm. If photos of the same tree or farm appear in both training and validation sets, accuracy will be inflated; split by farm or date where the metadata allows.

7. From a classifier to market information

A leaf classifier on its own does not move prices. Its value comes when it is aggregated:

  • Field surveys: counting the share of diseased leaves across sampled farms gives an early, quantitative read on crop health, ahead of official estimates.
  • Satellite and drone imagery: the same CNN approach, applied to canopy images, maps stressed or dying plantations at scale. The Google Earth Engine tutorial covers vegetation indices from satellites.
  • Yield models: disease prevalence can be added as a feature alongside weather in crop forecasts.
