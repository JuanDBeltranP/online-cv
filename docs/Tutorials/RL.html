Reinforcement Learning 101: Q-Learning on Sugar Market Regimes

Written in 2024. All examples use public data and are for learning only, not investment advice.

Supervised learning predicts; reinforcement learning (RL) decides. An RL agent takes actions, observes the consequences and learns a policy that maximises long-run reward. That framing suits trading, hedging and storage decisions in commodities, where today’s action changes tomorrow’s position and costs.

In this tutorial we build tabular Q-learning from scratch on weekly raw sugar prices. It is deliberately simple, so every moving part is visible.

1. The building blocks

  • Agent: the decision-maker (our trading rule).
  • Environment: the market, replayed from history.
  • State: what the agent observes, here the market regime.
  • Action: short, flat or long one unit of sugar.
  • Reward: the profit or loss from the position over the next week, minus transaction costs.

The agent learns a Q-table: for each state and action, the expected discounted future reward. It updates the table after every step with the Bellman equation:

\[ Q(s,a) \leftarrow Q(s,a) + \alpha \left[ r + \gamma \max_{a'} Q(s',a') - Q(s,a) \right] \]

where α is the learning rate and γ the discount factor.

2. Defining states from market regimes

Tabular Q-learning needs a small, discrete set of states. We describe each week by two features, each split into buckets:

  • Trend: 13-week return in three buckets (down, sideways, up).
  • Volatility: 13-week realised volatility in two buckets (calm, stressed).
  • Current position: short, flat or long, so the agent can account for trading costs.

That gives 3 × 2 × 3 = 18 states.

import numpy as np
import pandas as pd
import yfinance as yf

px = yf.download("SB=F", start="2008-01-01", end="2024-06-30", interval="1wk")["Close"].squeeze()
ret = np.log(px).diff()

trend = ret.rolling(13).sum()
vol = ret.rolling(13).std()

df = pd.DataFrame({"ret_next": ret.shift(-1), "trend": trend, "vol": vol}).dropna()
train = df.loc[:"2018-12"].copy()
test = df.loc["2019-01":].copy()

# Bucket edges from the training period only
t_edges = train["trend"].quantile([1/3, 2/3]).values
v_edge = train["vol"].median()

for d in (train, test):
    d["t_bin"] = np.digitize(d["trend"], t_edges)        # 0, 1, 2
    d["v_bin"] = (d["vol"] > v_edge).astype(int)         # 0, 1

3. The environment

ACTIONS = np.array([-1, 0, 1])   # short, flat, long
COST = 0.0005                    # cost per unit traded, as a fraction of price

def state_id(t_bin, v_bin, pos):
    return (t_bin * 2 + v_bin) * 3 + (pos + 1)

def step(row, pos, action_idx):
    new_pos = ACTIONS[action_idx]
    reward = new_pos * row.ret_next - COST * abs(new_pos - pos)
    return new_pos, reward

4. Training the agent

rng = np.random.default_rng(0)
Q = np.zeros((18, 3))
alpha, gamma = 0.05, 0.9
epsilon, eps_min, eps_decay = 1.0, 0.05, 0.995

rows = list(train.itertuples())
for episode in range(500):
    pos = 0
    for i in range(len(rows) - 1):
        s = state_id(rows[i].t_bin, rows[i].v_bin, pos)
        a = rng.integers(3) if rng.random() < epsilon else int(Q[s].argmax())
        pos, r = step(rows[i], pos, a)
        s_next = state_id(rows[i + 1].t_bin, rows[i + 1].v_bin, pos)
        Q[s, a] += alpha * (r + gamma * Q[s_next].max() - Q[s, a])
    epsilon = max(eps_min, epsilon * eps_decay)

The ε-greedy rule makes the agent explore random actions early on, then increasingly exploit what it has learned.

5. Reading the learned policy

labels = ["short", "flat", "long"]
policy = []
for t in range(3):
    for v in range(2):
        s = state_id(t, v, 0)
        policy.append({"trend": ["down", "sideways", "up"][t],
                       "vol": ["calm", "stressed"][v],
                       "action_from_flat": labels[int(Q[s].argmax())]})
pd.DataFrame(policy)

If the agent has learned something like “long in calm up-trends, flat in stressed markets”, it has rediscovered a trend-following rule with a volatility filter. That is a good sign the machinery works, and a reminder that RL often finds familiar strategies.

6. Testing on unseen years

pos, pnl = 0, []
for row in test.itertuples():
    s = state_id(row.t_bin, row.v_bin, pos)
    pos, r = step(row, pos, int(Q[s].argmax()))
    pnl.append(r)

pnl = pd.Series(pnl, index=test.index)
print("Test cumulative log return:", round(pnl.sum(), 3))
print("Buy and hold:", round(test["ret_next"].sum(), 3))
print("Weekly Sharpe (annualised):", round(np.sqrt(52) * pnl.mean() / pnl.std(), 2))

7. Limits of tabular Q-learning

  • Few states: real markets need far richer descriptions (curve shape, positioning, weather), which explode the table size.
  • One history: the agent sees each historical path many times and can memorise it. Out-of-sample testing is essential.
  • No market impact: we assume we can trade at the close with a fixed cost.
